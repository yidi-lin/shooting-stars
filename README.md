# Shooting Stars

A night sky over moonlit dunes. Hover a star to lock on and see how it shines up close, press to draw the bow, release to shoot — every star bursts into its own firework (gold, blue and purple star rain, willow, chrysanthemum, frost, feathers, paper confetti, cherry blossom, lego, candy, cloud, crystal, water, saturn, heart, butterflies, snowflakes, fireflies, galaxy, crackle) and the pieces fall back down onto the sand.

Live: https://yidi-lin.github.io/shooting-stars/

Single `index.html`, WebGL2, no dependencies.
